# hls_downloader_gui

This repository is used to store release assets for the HLS Downloader GUI.

## ms-playwright bundle

The `ms-playwright.zip` file in the GitHub Release assets contains the Playwright browser files required by the application.

The application should download only the following release assets:

- `ms-playwright.zip`
- `ms-playwright.zip.sha256`

Do not download the automatically generated GitHub source code files:

- `Source code (zip)`
- `Source code (tar.gz)`

## Version

The current Playwright browser bundle version is recorded in:

```text
ms-playwright.version
